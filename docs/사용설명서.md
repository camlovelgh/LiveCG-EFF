# LiveCG-EFF 처음 사용 설명서

**대상 버전: v1.6.1 · Windows x64**
LiveCG-EFF는 PNG·JPG·BMP·정적 WebP 이미지의 원하는 부분을 직접 지정하고, 모션을 편집해 투명 WebM 또는 OBS 브라우저 패키지로 출력하는 라이브커머스 그래픽 편집기입니다. 이미지에서 가격을 자동으로 찾거나 소리를 만드는 프로그램은 아닙니다.

## 1. 다운로드와 실행

1. [LiveCG-EFF 최신 배포](https://github.com/sunjoo1968-design/LiveCG-EFF/releases/latest)를 엽니다.
2. 최신 Windows ZIP 파일을 내려받아 작업 폴더에 압축을 풉니다. ZIP 안의 파일을 직접 실행하지 마세요.
3. 압축을 푼 폴더의 최상단에 있는 `LiveCG-EFF.exe`를 실행합니다.
4. `app`, `사용안내`, `licenses` 폴더는 실행 파일과 함께 보관합니다. 앱의 동작 파일이나 라이선스 고지를 옮기거나 삭제하지 마세요.

배포 ZIP에는 실행에 필요한 .NET, 그래픽 구성 요소, FFmpeg가 포함되어 있어 별도 런타임 설치가 필요하지 않습니다. 처음 실행할 때 Windows 보안 알림이 표시되면 파일이 공식 LiveCG-EFF 릴리스에서 내려받은 것인지 확인하세요. 실행 후 업데이트 확인 안내가 나오면 현재 작업을 저장한 다음 안내에 따라 업데이트할 수 있습니다. 업데이트는 내려받은 파일의 확인이 끝난 뒤 적용됩니다.

## 2. 화면 구성

화면은 크게 세 구역으로 나뉩니다.

| 구역 | 주로 하는 일 |
|---|---|
| 왼쪽 자료·출력 패널 | 이미지 가져오기, 자료 선택, 출력 종류·반복·폴더·파일 설정 |
| 가운데 미리보기와 타임라인 | 영역을 직접 그리고, 효과 클립을 배치·재생·수정 |
| 오른쪽 효과·레이어 패널 | 기본 효과, NEW 효과, 내 효과, 즐겨찾기 선택 및 영역·그룹 관리 |

화면 아래의 타임라인에는 선택한 영역의 효과 클립과 재생 구간이 표시됩니다. 화면 폭이 좁으면 도구줄을 좌우로 이동하거나 프로그램 창을 넓혀 작업하세요. 메뉴나 버튼의 이름은 배포 버전에 따라 약간 달라질 수 있습니다.

## 3. 첫 작업: 이미지에서 영역 지정하기

### 이미지 가져오기

- 파일을 왼쪽 자료 목록이나 빈 편집 화면으로 끌어다 놓습니다.
- 또는 **이미지 / 폴더**를 눌러 한 장 또는 폴더의 이미지를 가져옵니다.
- 여러 파일을 고를 때 `Ctrl` 또는 `Shift`를 사용할 수 있습니다. 가격 글자나 숫자를 자동으로 탐지하지 않으므로 모션을 줄 부분을 직접 지정합니다.

입력 형식은 PNG, JPG/JPEG, BMP, 정적 WebP입니다. 투명 PNG/WebP의 투명도는 유지됩니다. JPEG/BMP처럼 투명도가 없는 파일은 그 자체로 투명 배경이 되지 않습니다.

### 효과를 적용할 부분 그리기

1. 가운데 미리보기에서 **＋ 직접 지정**을 누릅니다.
2. 도형 도구에서 사각형, 원/타원, 둥근 사각형, 자유손 또는 포인트 펜을 고릅니다.
3. 이미지에서 효과를 줄 문구·숫자·배지 등을 둘러싸도록 드래그하거나 점을 찍어 영역을 완성합니다.
4. 영역을 선택하고 크기·위치를 조정합니다. 영역 이름은 오른쪽 레이어 목록에서 더블클릭하거나 `F2`로 알아보기 쉽게 바꿀 수 있습니다.
5. 필요하면 모양을 바꾸거나 점 편집으로 가장자리를 다듬습니다. 처음에는 문구 전체보다 개별 단어·가격처럼 작은 영역 하나로 시험하는 것이 편합니다.

한 이미지에 영역을 여러 개 만들 수 있습니다. 예를 들어 상품명, 가격, 할인율에 각각 영역을 만들면 서로 다른 모션과 시작 시점을 줄 수 있습니다. 레이어 목록의 눈 모양은 표시/숨김, 잠금은 실수로 움직이는 것을 막습니다. 같은 그룹 안에서 레이어 행을 끌어 순서를 바꿀 수 있습니다.

### 배경과 글자 분리

단색 배경 위의 글자나 오브젝트만 움직이려면 영역의 **배경 고정·내용만** 설정과 배경색/스포이드 조절을 사용합니다. 자동 분리 결과에 구멍이나 남은 배경이 있으면 **정밀 분리·보정**의 자동 분리, 브러시 보정, 결과 확인을 차례로 사용합니다. 글자 안쪽(예: ㅇ, ㅁ)을 다룰 때는 글자·획 보존 옵션을 확인합니다.

자동 분리는 단색 또는 지정한 색 범위를 기준으로 동작합니다. 사진 배경에 가려진 픽셀을 새로 그려 복원하지는 않습니다. 복잡한 무늬·그라데이션·글자와 배경의 동일 색상은 브러시로 직접 보정해야 할 수 있습니다. 원본 이미지는 수정하지 않습니다.

## 4. 모션 효과 적용하기

### 기본 효과 적용

1. 영역을 클릭해 선택합니다. 선택 상태는 미리보기 안내와 오른쪽 패널에서 확인할 수 있습니다.
2. 오른쪽 **기본 효과**에서 원하는 효과를 고릅니다. 효과 이름을 누르면 선택 영역에 적용합니다.
3. 효과 썸네일 또는 효과 이름을 선택하고 **→ 뒤에 추가**를 누르면 해당 영역의 기존 클립 다음에 붙습니다.
4. 재생 커서를 놓은 위치에서 시작하게 하려면 **◆ 커서에 추가**를 사용합니다.
5. 같은 영역에 여러 효과를 추가해 순서대로 재생할 수 있습니다. 예를 들어 먼저 부드럽게 등장시키고, 다음 클립에서 살짝 흔들리게 할 수 있습니다.
6. 타임라인의 클립을 선택해 길이, 강도, 반복 등 표시되는 속성을 조정합니다. 미리보기 재생으로 움직임과 영역 경계를 확인합니다.

기본 효과에는 페이드·방향 등장·줌·바운스·흔들림·부유·숫자 롤링·빛/광채/반짝임·테두리·형광펜 계열 등이 있습니다. 실제 목록은 효과 분류와 검색 결과에 따라 표시됩니다. 숫자 롤링은 숫자 영역에 적용하는 효과입니다. 글자가 잘리지 않도록 주변에 여유 공간을 두세요.

### 효과의 타이밍 정하기

효과 클립은 시작 시점과 길이를 가집니다. 타임라인에서 클립을 선택해 이동하거나 가장자리를 당겨 길이를 조절합니다. 타임라인을 클릭해 재생 커서를 옮기고 재생 버튼으로 해당 시점의 모습을 봅니다. 타임라인에서 선택한 클립은 `←`/`→`로 1프레임씩 이동하고 `Shift+←`/`Shift+→`로 10프레임씩 이동합니다.

선택 효과를 마우스 오른쪽 버튼으로 눌러 즐겨찾기에 추가하거나 제거할 수 있습니다. 즐겨찾기 탭에서 이름을 누르면 현재 선택 영역에 적용됩니다. 자주 쓰는 효과를 미리 등록해 두면 목록을 매번 검색하지 않아도 됩니다.

## 5. 등장·반복·퇴장과 타임라인

**구간 설정**은 클립들을 등장, 반복, 선택형 퇴장 재생 구간으로 나눕니다. 처음에는 효과 기준 자동 구간을 사용하고, 필요한 경우 타임라인의 구간 바 경계를 직접 당겨 조절합니다. 경계 시간은 정밀 설정에서 초 또는 프레임 단위로 입력할 수도 있습니다.

- **등장**: 장면에 처음 나타날 때 재생할 동작입니다. 보통 한 번 실행합니다.
- **반복**: 계속 반복되어 보여 줄 동작입니다. OBS 브라우저 출력에서는 등장 이후 반복 구간이 이어집니다.
- **퇴장**: 장면에서 사라질 때 요청해 재생할 동작입니다. OBS에서 소스를 숨기기 전에 퇴장을 요청합니다.
- **구간 바 조절**: 타임라인 위 구간 바의 끝을 끌어 구간 길이를 바꾸고, 반복 바의 가운데를 끌어 구간 위치를 옮깁니다. 자동 구간을 직접 조작하면 직접 조절로 전환됩니다.

왼쪽의 **반복·출력 길이**에서는 WebM 반복 횟수(1~100회), 반복 사이 쉬기(0~30초), 쉬는 동안 보일 모습을 설정합니다. 이 값은 타임라인 구간 설정과 연동됩니다. 쉬는 모습은 원본 유지, 마지막 모습 유지, 전체 투명 중에서 선택할 수 있습니다. WebM은 마지막 반복 뒤에는 쉬기를 추가하지 않습니다. OBS 브라우저 출력은 반복을 계속 이어갑니다.

WebM 길이는 대략 `등장 길이 + (반복 길이 × 횟수) + (쉬기 × (횟수−1)) + 퇴장 길이`입니다. 실제 프레임 수와 시간은 출력 FPS에 맞춰 반올림됩니다. 출력 전에 **1회 + 쉬기 확인**으로 반복 한 번과 쉬기 동작을 점검하세요.

## 6. NEW 효과·즐겨찾기·내 효과

### NEW 효과

오른쪽 **NEW 효과** 탭에서 최근 추가된 효과, 키프레임 모션, 여러 동작을 묶은 프리셋을 확인합니다. 항목을 선택해 **삽입**하면 현재 선택 영역에 프리셋을 추가할 수 있습니다. 기본 효과처럼 뒤에 이어 붙이거나 커서 위치에서 시작하려면 해당 추가 버튼을 사용하세요.

프리셋은 먼저 시험 재생하고, 타이밍이나 속성을 프로젝트에 맞게 조절하세요. 선택한 타임라인 클립을 프리셋으로 바꿀 때는 **클립 교체**를 사용합니다. 선택 클립의 시작 위치를 유지합니다. **삽입**은 선택 효과 바로 뒤에 들어가며, 선택이 없으면 해당 영역의 끝에 붙습니다.

현재 v1.6.1에는 블록 타일 조립, 타자기식 순차 등장, 글자별 회전 상승, 양쪽에서 문구 합류를 비롯한 사용 효과/모션 프리셋이 반영되어 있습니다. 항목별 제공 여부와 이름은 설치한 버전의 **NEW 효과** 목록을 기준으로 확인하세요. 미리보기에서 결과가 마음에 들지 않으면 되돌리거나 다른 효과로 교체할 수 있습니다.

참고: 반짝임·형광펜·밑줄 형광펜은 최신 버전에서 재생 클립 효과로 동작하지 않는 항목입니다. 이 항목을 포함한 오래된 작업을 열었다면 타임라인에서 해당 클립을 선택해 지원되는 효과로 교체하세요.

### 즐겨찾기

즐겨찾기 탭에서 **＋ 즐겨찾기에 넣을 효과 선택**을 펼쳐 효과나 프리셋을 체크하거나, 효과 목록에서 항목을 우클릭해 **즐겨찾기에 추가**를 선택합니다. 즐겨찾기 목록의 효과 이름을 클릭하면 적용합니다. 목록에서 제거 버튼을 누르거나 우클릭 메뉴로 즐겨찾기에서 뺄 수 있습니다.

### 내 효과와 직접 만든 모션

- **새 모션**: 위치, 크기, 회전, 불투명도, 기준점, 상·하·좌·우 크롭의 키프레임을 작성해 사용자 모션을 만듭니다. 키를 추가해 각 시점의 값을 기록하고 재생으로 확인한 뒤 효과 에셋으로 저장합니다.
- **조합 저장**: 현재 선택한 효과 클립 조합을 프리셋으로 저장합니다.
- **삽입 / 편집**: 저장한 프리셋을 현재 영역에 적용하거나 내용을 수정합니다.
- **효과 폴더 / 새로고침**: 사용자 효과 파일을 관리하는 폴더를 열거나, 폴더에 추가한 파일을 다시 읽습니다.

사용자 효과 에셋은 `.lcgeffect.json` 형식입니다. 새 에셋은 앱의 **내 효과 → 효과 폴더**를 눌러 열린 폴더에 저장하고 **새로고침**합니다. 다른 사용자에게 전달할 때는 해당 JSON 파일도 함께 전달합니다. 템플릿이나 효과 파일에 원본 이미지가 자동으로 들어가는 것은 아니므로 이미지와 작업 파일을 별도로 보관하세요.

## 7. 미리보기와 출력

### 출력 방식 선택

왼쪽 출력 설정에서 다음 중 선택합니다.

- **OBS 브라우저 패키지**: OBS에 HTML 브라우저 소스로 등록합니다. 기본 출력 방식입니다.
- **WebM 영상**: 투명 WebM 영상 파일을 만듭니다. 반복 횟수와 영상 품질을 설정할 수 있습니다.
- **WebM + OBS 둘 다**: 두 종류의 결과를 함께 출력합니다.

OBS 패키지는 원본 폴더 아래 `OBS 출력` 폴더에 생성되는 것을 기본으로 합니다. 출력 폴더에는 자료별 HTML과 숨김 `.livecg` 폴더가 있습니다. OBS에 등록한 후 폴더 이름이나 위치를 바꾸면 소스 경로가 끊길 수 있으니, 이동 시에는 폴더 전체를 함께 복사하고 OBS의 로컬 파일 경로도 다시 연결합니다.

### 출력 전 점검

1. 미리보기에서 각 영역의 모션과 레이어 순서를 확인합니다.
2. 타임라인의 등장·반복·퇴장 경계와 반복 쉬기를 확인합니다.
3. **출력 예정 목록 확인**에서 파일명, 길이, 출력할 자료, 같은 이름 파일과의 충돌 여부를 확인합니다.
4. 출력 형식, FPS, 품질, 폴더를 설정한 뒤 출력합니다. 일부 자료만 다시 출력하려면 자료 목록에서 해당 항목을 우클릭해 개별 출력을 선택합니다.
5. 기존 OBS HTML을 갱신하는 경우에는 앱의 **저장·방송 갱신**을 사용한 뒤 OBS에서 소스를 한 번 새로고침합니다.

앱 미리보기는 편집 확인용입니다. OBS 스튜디오 모드 전환·브라우저 합성·투명 경계까지 최종 확인하려면 OBS 프로그램 화면에서 실제 출력 결과를 점검하세요.

## 8. OBS에 연결하기

1. OBS에서 장면을 선택하고 **소스 → + → 브라우저**를 선택합니다.
2. 소스 이름을 정하고 **로컬 파일**을 켭니다.
3. LiveCG 출력 폴더에서 해당 자료의 `.html` 파일을 선택합니다. 화면 크기와 FPS 값은 함께 출력된 `사용안내.txt`를 확인해 입력합니다.
4. 브라우저 소스의 **소스가 활성화될 때 브라우저 새로고침**, **장면이 활성화될 때 새로고침** 옵션은 재생에 문제가 있으면 끕니다.
5. 장면 전환 시 등장부터 재생하려면 앱의 구간 설정에서 **OBS 프로그램 전환 시 처음부터 재생**을 켜고 패키지를 다시 출력합니다.
6. 브라우저 소스의 **상호작용** 창에서는 `R` 재등장, `E` 퇴장, `Space` 일시정지/계속을 사용할 수 있습니다. 퇴장 효과는 소스 눈 아이콘으로 숨기기 전에 실행하세요.

OBS에 추가 브라우저 플러그인이나 인터넷 연결은 필요하지 않습니다. 출력 HTML과 같은 출력 폴더의 `.livecg` 데이터가 함께 있어야 하므로 HTML만 따로 옮기지 마세요. 같은 브라우저 소스를 여러 장면이 공유하고 프로그램 화면에 계속 활성 상태로 남겨 두면 다시 진입한 것으로 감지되지 않을 수 있습니다. 장면별 별도 소스를 두거나 상호작용에서 `R`을 눌러 재시작할 수 있습니다.

### 순차 블러 강조

상품 소개 중 강조할 대상을 차례로 확대하는 경우, 원본 편집 화면에서 블러 영역과 강조 영역을 직접 그립니다. 우측 **효과 → 순차 블러 강조**에서 순서, 확대, 블러량과 전환 길이를 설정한 뒤 OBS 브라우저 패키지를 출력합니다. OBS **도구 → 스크립트**에서 배포본의 `LiveCG-OBS-Hotkeys.lua`를 추가하고, OBS 설정의 단축키 메뉴에서 다음 강조·이전 강조·전체 블러·처음부터 키를 지정합니다. 이미 이전 스크립트가 등록되어 있으면 등록된 경로의 파일을 새 버전으로 교체하고 스크립트를 다시 불러옵니다.

v1.5.11 이상 배포본은 투명 가장자리 보정 옵션을 포함합니다. OBS에서 가장자리가 어둡거나 밝게 보이면 배포 폴더의 LiveCG OBS 스크립트 버전과 OBS 혼합 방식을 확인하세요. 기존 HTML을 새 기능에 맞출 때는 패키지를 다시 출력하거나 **저장·방송 갱신**을 실행합니다.

## 9. 저장·자료 교체·다른 PC로 옮기기

작업 메뉴에서 프로젝트를 저장하고 다음 작업에서 다시 엽니다. 프로젝트에는 편집 영역, 효과, 타임라인 설정이 기록되지만 원본 이미지가 항상 포함되는 것은 아닙니다. 작업 파일, 원본 이미지, 출력 폴더를 함께 보관하세요.

- 기존 자료의 이미지만 교체할 때는 자료 목록에서 우클릭해 **원본 이미지 교체** 또는 **원본 다시 연결**을 선택합니다. 기존 영역과 클립은 유지되지만, 새 이미지 크기나 내용에 따라 분리 마스크와 숫자 경계를 다시 확인해야 합니다.
- 다른 PC로 옮길 때는 **작업 → 이동용 작업 저장**을 사용하거나 작업 파일·원본·OBS 출력 폴더 전체를 복사합니다. 출력 폴더 안의 숨김 `.livecg`도 포함해야 합니다.
- OBS 장면 모음의 브라우저 파일 경로까지 바뀌면 **작업 → 다른 PC OBS 연결** 안내를 사용해 OBS 장면 파일의 경로를 다시 연결합니다.
- 방송 중 업데이트는 작업을 열어 이미지와 효과를 확인한 뒤 **저장·방송 갱신**합니다. OBS가 같은 HTML을 참조하도록 출력 경로와 파일명을 유지하세요.

## 10. 작업 중 자주 쓰는 조작

| 키/조작 | 기능 |
|---|---|
| `←` / `→` | 선택한 클립을 1프레임 이동 |
| `Shift` + `←` / `→` | 선택한 클립을 10프레임 이동 |
| `Ctrl` + 클릭 | 타임라인 클립 여러 개 선택 |
| `Ctrl+C` / `Ctrl+V` | 클립 복사 / 재생 커서 위치에 붙여넣기 |
| `Ctrl+Z` / `Ctrl+Y` | 되돌리기 / 다시 실행 (`Ctrl+Shift+Z`도 다시 실행) |
| `Ctrl+K` | 재생 커서에서 클립 분할 |
| `R` / `V` | 영역 그리기 / 선택 모드 |
| `Tab` / `Shift+Tab` | 다음 / 이전 영역 |
| `1`~`9` | 번호에 해당하는 영역 선택 |
| `Delete` / `Esc` | 선택 삭제 / 현재 그리기·드래그 취소 |
| 영역 이름 더블클릭 또는 `F2` | 레이어 이름 편집 |
| 슬라이더의 `↔` 부분 드래그 | 세밀하게 값 조절 (`Shift`는 더 세밀한 조정) |

텍스트 입력 중에는 일부 단축키가 텍스트 편집에 사용됩니다. 영역 이동·도형 편집용 단축키를 변경하려면 앱의 단축키 설정을 확인합니다.

## 11. 문제 해결

### OBS에서 아무것도 보이지 않음

- 브라우저 소스의 **로컬 파일** 경로가 실제 `.html` 파일인지 확인합니다.
- HTML만 복사하지 말고 같은 출력 폴더의 숨김 `.livecg` 폴더도 확인합니다.
- 브라우저 소스의 너비·높이를 출력 사용안내에 맞추고, 소스/장면 활성화 새로고침 옵션을 꺼서 확인합니다.
- 이미지나 작업 경로를 옮겼다면 HTML 출력 경로를 다시 지정합니다.

### 새 모션이 목록에 없음

**내 효과 → 효과 폴더**를 열어 `.lcgeffect.json` 파일이 올바른 위치에 있는지 확인하고 **새로고침**을 누릅니다. 기본 효과가 아니라 최근 추가된 모션이라면 **NEW 효과** 탭을 확인합니다.

### 변경한 효과가 OBS에 반영되지 않음

프로젝트를 저장하고 **저장·방송 갱신**을 실행합니다. OBS의 브라우저 상호작용 또는 우클릭 메뉴에서 새로고침합니다. 방송 중이라면 송출에 영향을 주지 않도록 테스트 장면에서 먼저 확인합니다.

### 글자 주변 배경이 남거나 글자 획이 사라짐

배경색을 다시 스포이드로 지정하고 정밀 분리 결과를 확인합니다. 포함/제외 브러시로 남길 픽셀과 지울 픽셀을 보정합니다. 배경과 글자가 완전히 같은 색인 이미지에서는 자동으로 둘을 구분할 수 없으므로 수동 보정이 필요합니다.

### 업데이트가 되지 않음

인터넷 연결을 확인하고, 공식 GitHub 릴리스 페이지에서 ZIP을 직접 내려받아 새 폴더에 풀어 실행합니다. 기존 작업 파일, 이미지, 사용자 효과 폴더를 지우지 말고 별도로 보관합니다. 실행 프로그램을 기존 폴더에 덮어쓰기 전에 방송용 출력과 사용자 파일을 백업합니다.

## 12. 기능 범위와 주의사항

- 가격 자동 탐지/OCR, 사운드 생성, 사진 배경의 가려진 부분 복원 기능은 없습니다.
- 애니메이션 WebP, PSD, AI, SVG 입력은 지원 범위에 포함되지 않습니다. 정적 WebP만 사용하세요.
- 배경 제거는 이미지에 실제로 있는 픽셀을 분리하는 방식입니다. 투명 배경이 원본에 없으면 영역 분리나 마스크를 설정해야 합니다.
- 효과를 너무 많이 한꺼번에 적용하면 문구가 읽기 어려워질 수 있습니다. 각 영역에 한두 가지 모션을 먼저 시험하고, 반복 구간에서 움직임이 계속 보여야 하는지 확인하세요.
- 라이선스와 외부 구성 요소 안내는 프로그램 배포본의 `licenses` 폴더 및 저장소의 `THIRD_PARTY_NOTICES.md`를 확인합니다.

## 13. 개발 버전 업데이트 흐름

이 저장소는 원본 통합 저장소 `sunjoo1968-design/LiveCG-EFF`를 `upstream`, 사용자 포크 `camlovelgh/LiveCG-EFF`를 `origin`으로 연결해 개발을 이어갑니다. 새 원본 버전을 받아 사용자 포크에 반영할 때는 저장소 폴더에서 다음 순서로 진행합니다.

```powershell
git status
git fetch upstream
git merge upstream/main
# 충돌이 있으면 파일 내용을 비교해 양쪽 기능을 보존하고 해결한 뒤
git add <해결한 파일>
git commit
git push origin main
```

`git reset --hard` 또는 강제 푸시는 로컬 모션 작업이나 원격 이력을 덮어쓸 수 있으므로 일반 업데이트에 사용하지 않습니다. 먼저 `git status`가 깨끗한지 확인하고, 업데이트 전에 작업 중인 코드와 사용자 효과 파일을 커밋하거나 별도로 보관합니다. 일반 사용자는 배포 ZIP을 내려받아 사용하면 되며 이 개발 절차는 필요하지 않습니다.
